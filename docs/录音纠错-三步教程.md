# 录音纠错：跟着页面走

版本：1.6.67.0；日期：2026-10-25；状态：现行。完整图文示例见[使用说明书](录音纠错使用说明书.html)。

1. 打开「词典 → 听写记录 → 录音」，开启「保存听写录音」后从下一轮留档，或点「补录一句」。单击只选中；双击、Enter或「打开录音」进入纠错。
2. 播放原音，在「修改后的文字（可编辑）」填写实际说出的完整内容。需要训练才勾「留作训练」，然后保存；自动继续下一条，最后一条返回列表。通过「筛选 → 已保存」回看，取消训练勾选并保存可撤选。
3. 进入「训练 → 待归档」，填写批次名、二次勾选录音，确认数量和时长后「归档批次」。在「已归档」打开批次交给agent，独立训练候选。候选登记后，在「验证」录新音，核对原模型与候选全文，再通过或打回。通过仍须agent完成通用回归、实际启用和回滚准备。

归档可以撤回或恢复，原音和快照不改；验证结论可撤回，实际模型回滚须另行执行。录音列表「多选 → 批量操作」支持状态管理和永久删除；永久删除不可撤销，既有归档与验证副本保留。纠错页单条删除仅移出列表，原音保留。

「还原本次编辑」只恢复未保存修改；「撤销上次」恢复最近20组保存或状态操作，仅限当前窗口。保存录音、挑选材料和归档都不等于已训练。
