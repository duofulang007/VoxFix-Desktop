# VoxFix Desktop 1.1.0 流式维护

## 已修复

- 旧版 WinMM 仅有一个三分钟缓冲，停止后才读取；识别调用 session.run 整段处理，造成模型支持流式但产品不流式。现改为 32 个 100ms 循环缓冲，持续读取并送入同一流式会话，结束时 reset 采集设备、排空尾缓冲，再 finalize。
- JSON 协议改为 start/audio/stop/cancel 与录音编号校验；单个会话串行收发，停止等待当前块完成后再送尾部，防止交错和串段。
- 直接向目标输入位置追加模型 committed 文本，保留英文空格；最后一次返回仅追加新增部分，避免重复全文。不通过退格反复修订目标应用原文。
- 加入键鼠操作与焦点保护。输入标记区分自身 Unicode 注入；操作其他位置或编辑时停止录音，保存未输入的已识别文本，不继续追着光标输入。
- 错误不再永久禁用按钮，点击可重新加载服务。拖动限制在工作区；录音长度从样本端精确限制为三分钟，防止计时抖动多送尾帧而触发服务错误。
- 去掉临时 WAV 路径，录音仅在内存里传输。恢复文字保存异常也提供可见文本，不因恢复文件写入失败再次崩溃。

## 验证证据

- `tools/test_microphone.py` 真实模型与真实协议：按音频墙钟节奏投递，停止前已有 partial；首批文字在一条约 4 秒测试录音上约 1206ms。测试还覆盖 627ms 短词、数字静音、空结束、连续会话、取消、错误 PCM 恢复、英文空格与尾部样本数无丢失/重复。
- `--self-test`：Windows x64 INPUT 布局、Unicode、文本追加、英文空格、重复结果、回退保护与图形绘制。
- `--stream-test`：真实 DLL、真实 Win32 SendInput、自有原生输入框；已完成一次完整通过，确认停止前输入、原文不删除、最终结果不重复、自身注入不触发编辑保护、外部按键和焦点变化会中止输入。测试中真实外部键鼠操作会触发保护，因此该测试需要不操作测试输入框以外的位置。
- `--capture-test`：在实际交互桌面打开本机默认麦克风，250/450/650ms 三轮的 PCM 字节计数分别为 8258/15298/21058；持续读取、尾缓冲与反复打开关闭通过。测试不存储或上传音频。

## 限制

尚未对用户本人讲话和所有常用软件做日常验收，不能据此宣称所有问题已消除。约 1.2 秒首批文字是当前模型、运行时及配置下的一条测试结果，不是普遍保证。SendInput 的成功计数不等于每个应用已经接受文本；管理员窗口、富文本和应用自动移动光标仍须分别验收。没有新增个人学习与模型微调。
