# 词典圆角与删除撤回

- 版本：1.6.42.0
- 日期：2026-10-23
- 状态：部分历史；系统边框/圆角实现已因实屏回归在 1.6.43.0 修正，见 [修复记录](词典系统标题条回归修复-2026-10-23.md)。删除确认及撤回行为仍现行。

## 问题与修复

用户实屏反馈说明图标像是穿过标题、部分标签被截断，外沿圆角存在明显棱角；删除没有二次确认或撤回。

- `DictionaryLabel` 使用与 `DrawString` 一致的字体渲染方式测量尺寸；说明图标透明绘制并跟随标题实际宽度定位，避免硬编码位置与原生标签测量差异。
- `DictionaryWindow` 保留系统框架信息但自绘客户区，使用 DWM 圆角偏好和系统外沿，移除主窗的 `Region` 裁切。删除确认窗复用同一表面。
  [微软说明](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners)指出，自定义窗口区域会使系统无法圆角；该接口是系统提示，实际效果仍受系统环境影响。
- `DictionaryDeleteDialog` 使用暖白底、同字体与深色确认按钮；初始焦点/Enter 为取消，Esc 取消。确认前不从列表移除任何词语。
- 确认删除前先提交当前错法编辑，保留完整 `WordGroup`、原位置和独立的单调时钟截止时间。窗口底部悬浮条显示最近一次删除与剩余秒数，10 秒后不再接受撤回。
- 连续删除保留各自的撤回记录，不用新删除覆盖旧记录；撤回按最近优先恢复，保留错法、`context` 和列表位置。同名词在撤回期内重新添加会恢复原记录，不丢旧错法。
- 保存不清除尚未过期的撤回机会；保存后再撤回会重新标记未保存，须再次保存。退出当前词典窗口即结束本轮撤回，计时器随窗口释放。

- 确认/取消真实按钮、删除前未保存错法、完整恢复与顺序、连续删除、超时拒绝撤回、保存后撤回、重新添加同名词等均加入 `TIDY-TEST PASS`。
