# 词典交互与视觉检查

版本：1.6.58.0

日期：2026-10-24

状态：现行；已修复本轮确认问题，非完整无障碍合规认证。

## 范围和方法

检查词语编辑、搜索/预览、删除/撤回、录音列表/纠错、材料预览、批量处理和批次交接。运行原生离屏真实控件用例，使用隔离索引和音频，未改个人数据。新增右键测试先在1.6.57源码上失败：HISTORY-TEST: right click on recording must not enter editor；修复后通过。按[W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)的4.5:1文字、3:1交互边界方法计算本机配色对比度，作为桌面设计检查基准，不宣称完整WCAG认证。

## 已确认并修复

| 问题 | 影响 | 修复及验证 |
|---|---|---|
| 录音和材料行MouseClick未限制鼠标按钮 | 右键也误进编辑页 | 仅左键进入；反射重放实际控件右/左键事件 |
| 材料列表使用隐藏原生滚动条的控件，却没接自定义滚动条 | 录音超过可见区域时没有可拖动入口 | 复用DictionaryScrollBar；12行用例验证拖动、Home/End、滚轮 |
| 最后一条删除或过滤后，编辑页可能无记录仍保留选项 | 页面存在无目标管理入口 | 当前条目为空自动返回列表，保存不再显示；空状态用例 |
| 空白预览输出占一个Tab停靠位置 | 键盘停在没有内容的只读区域 | 仅有有效结果时进入焦点序列，过期/清空时跳过 |
| 空闲滚动条、未聚焦输入边界和次按钮边界太淡 | 交互区域不易辨认 | 保持暖白底，仅加深功能边界，补输入框Enter/Leave重绘 |
| 选中录音行辅助文字仅4.39:1 | 未达到4.5:1检查基准 | 历史辅助文字微调为96/100/107，选中底4.81:1 |
| 非多选模式的空计数标签仍可占据鼠标区域 | 扩大列表后可能挡住底部录音点击 | 非多选模式隐藏计数标签，断言可见时不与行区域相交 |
| 当前项仅用相近灰底区分 | 选中状态不显著 | 词语/录音行与历史侧栏加细侧标识，侧栏补选中无障碍说明 |
| 提示引用已不存在的按钮名称和开关位置 | 操作指引不一致 | 改为左侧开关、训练说明等实际名称；筛选中恢复真实容量/数量统计 |

禁用控件不按正常可用文本对比度判断；空选择不能批量处理、无材料不能准备批次是有效保护，不能为了让按钮看起来可用而放开。现有页保留暖白主题，不加深纯装饰分割线。

## 层级、留白和无效控件

已检查标题20pt粗体、编辑正文15pt、标签11pt、辅助文字9.5–10pt；554px内容、固定主按钮及底栏几何用断言验证，标签不与输入区域或状态区重叠。普通录音列表增加38px可视高度，多选时让出勾选计数区域。少量记录的留白属于数据不足，不通过塞更多控件填满；长列表通过滚动处理。

本轮覆盖的可见按钮没有发现未接事件的空按钮。功能明确的筛选/选项/批量操作是菜单入口；正常禁用控件非死控件。filter/selected/compare是隐藏的旧状态绑定控件，不在用户焦点序列，不将其计为用户可操作的控件。已修复的空预览Tab和空记录选项属于真实无效交互。
