# VoxFix Desktop 中文识别暴力测试

日期：2026-10-20。测试使用本机 CPU、已有本地模型；没有下载新模型，没有上传或保存现场麦克风录音。

完成 **2175 次识别 + 150 次控制流程检查，共 2325 项**。基于 174 条固定音频，其中普通话/中英混说 126 条，普通话金标只有 71 个不同文本；其余运行来自变体、重复会话与对照，不是两千多条独立真人录音。

普通话和英文素材主要为 Microsoft 合成语音；公开粤语录音单列。结果能定位程序与模型问题，不能等同于用户真人口音准确率，也没有与 Win+H 做同音频对比。

## 主要结论

1. 停止补尾有可复现问题。送入的采样数完整，但旧版 finalize 会把“好的/备份/到账”截成“好/备/到”。通用追加 320ms 静音右上下文后恢复；320ms 与 500ms 的普通话整句全对数和总错误数相同，个别具体输出不同，采用较短者。补的是模型上下文，不是等待 320ms 或保存更多录音。
2. 20ms、100ms、320ms 与不规则分块在同一 76 条核心语料上得到相同文本，不能靠换采集块大小解决同音词错误。
3. 强制 zh-CN 没有提高普通话成绩，且严重损害纯英文输出，不采用。
4. 停止补尾之外仍有明显中文同音词和中英术语错误，不能宣称当前模型中文最强，也不能靠修 UI 消除。
