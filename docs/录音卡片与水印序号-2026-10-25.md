# 录音卡片与水印序号

版本：1.6.63.0；日期：2026-10-25；状态：现行。

借鉴手机候选剪贴板的分卡与底层序号，保留桌面紧凑信息密度、状态标签、侧栏和页脚。没有照搬手机大字号、两行高卡片、黄色匹配高亮、重阴影或多层灰色底板。列表背景与页面同色，避免少量记录后大片空灰。

HistoryCard统一绘制录音、训练（含只读归档）和验证。先画浅色右下水印，后画完整宽度正文，文字可以压在数字上；不为序号预留右列。数字是列表顺序，滚动保留，筛选/批次切换可重新编号，非永久数据ID。卡片留出分隔，当前记录灰侧标，勾选浅蓝底与圆角勾，避免把查看当勾选。

DictionaryCheckBox保留原生CheckBox交互/事件/无障碍，统一编辑页、保存开关和原文对照的圆角框；左40px列表勾选保留键盘空格，悬停/按下/键盘聚焦有反馈。验证仍只选查看，不增加多选。滚动条保留拖动、Home/End、滚轮，轨道更清楚；只对三处列表启用，不改词语区滚动外观。

验证：PowerShell构建成功；本轮 --dictionary-test退出0，CARD/REVIEW/HISTORY/TIDY-TEST PASS，原有保存/批量/归档/返回位置门禁持续通过。CARD-TEST覆盖1/99/100/1000、卡片分隔和正文真正覆盖水印像素，原生CheckBox单击/状态事件和空格按下反馈通过。work/dictionary-ui-audit.txt计算正文/辅助文字压水印对比度、白勾与蓝底对比度，文字门槛4.5。离屏截图包括dictionary-history.png、dictionary-history-materials.png、dictionary-verification.png和dictionary-card-states.png。

未改变采音、训练、模型、原音/标签和归档协议。未完成全量DPI缩放、屏幕阅读器或用户真实鼠标滚动主观验收。

字体：听写三模块正文、时间、标签、选择框、编辑和导航统一明确使用Microsoft YaHei UI；自绘正文、标签、水印启用AntiAliasGridFit，避免GDI+中西文回退与外部标签不一致。字号层级保留，不全局改动词语区与胶囊。补充截图dictionary-history-scroll.png覆盖有轨道的长列表。
