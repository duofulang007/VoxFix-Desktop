# 维护契约历史

版本：1.6.54.0–1.6.56.0；整理日期：2026-10-25；状态：历史，布局及入口已由1.6.57.0及后续规则覆盖。

本页保留原维护约定供追溯，当前规则见[AGENTS](../AGENTS.md)，当前操作见[使用说明](使用说明.md)。

1.6.50.0 起历史默认只显示一份可编辑文本和「选录音 → 听音改字 → 留作训练材料（可选）」三步，主按钮「保存」只在保存成功后前进，下一条不得自动勾选；「跳过」不改音频、标签、审核或训练选择。1.6.53.0 筛选精简为四类，搜索、原文对照、补录、重新核对、忽略、撤销和批次入口直接可见，更多仅留删除/统计；切换/关闭仍须处理未保存修改。未选材料时不允许点整理按钮，整理材料只准备快照，不宣称已经训练。教程见 `docs/录音纠错-三步教程.md`，窗口自检覆盖简洁默认态、按需对照、保存/失败/跳过/最后一条和常驻搜索。

## 1.6.54.0 分页与控件层级

- 默认录音列表页，仅放留档开关、补录/刷新、筛选/搜索、录音卡片及批量入口。点录音或按Enter直接进入纠错；批量模式只勾选不跳页，批量工具只在此模式显示。
- 独立纠错页负责播放、完整文字、可选原文对照、材料选择、重新核对/忽略及保存下一条，提供返回列表；还原编辑仅有未保存编辑时出现。删除/统计归此页录音操作。保存下一条不重复经过列表。
- 顶部训练材料导航进入独立页面，预览真实入选列表/数量/时长，准备/查看批次与训练验收说明仅在此页出现。材料点击可返回纠错。切页复用Resolve，取消不跳转，放弃须恢复上次保存值，停止播放。
- 本工作区按钮复用DictionaryButton，Outlined显式启用圆角边框，主要动作深色；不全局改变其他词典按钮外观。三个页面互斥可见，测试须断言不混显并逐页检查边界，输出列表/纠错/材料/批量四张离屏截图。

## 1.6.55.0 日常操作精简（覆盖旧版控件位置）

- 保留列表/纠错/材料分页；取消日常强制步骤和重复的进入按钮。点录音进入，大文本框编辑，唯一主动作保存，自动继续；最后一条回列表。
- 列表无常驻状态下拉/流程提示/刷新按钮，筛选按需打开并包含刷新和说明；多选才显示批量栏。纠错页仅播放、文字、选项、保存；对照/材料选择（明确勾选，保存生效）/还原/跳过/状态及删除在上下文选项。全局返回只在子页显示；材料入口仅在列表显示，撤销仅有历史时显示。
- 数据、明确训练选择、失败保存停留、未保存切页询问、撤销冲突、批次快照和训练边界不变。离屏自检覆盖新默认态、自动继续及返回和上下文入口。

1.6.56.0：简化控件不得删除输入区用途标签。纠错可编辑区常驻「修改后的文字（可编辑）」，对照区「原识别文字（只读）」，录音搜索显示「搜索」。自检须检查开/关对照时标签可见且在对应框上方，输出dictionary-history-comparison.png。
