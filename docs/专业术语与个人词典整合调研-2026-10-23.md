# 专业术语与个人词典整合调研

- 版本：VoxFix Desktop 1.6.44.0
- 日期：2026-10-23
- 状态：现行调研；方案未实施，未改生产代码、模型或个人词典
- 后续：本文的"领域词包"与"可选中文限制"两节已被[个人词典第一版方案](个人词典第一版方案-2026-10-23.md)取代（不设计多套词库、不加语言开关）；WhisPrompt 证据边界与 64 词/中文惰性的核对结论仍有效。
- 对象：用户已确认 WhisPrompt 为 https://whisprompt.ai/，不是其他同名提词器或 Wispr Flow。

## 结论

专业术语可以与现有个人词典结合。当前已经共用“正确词语 + 可选错法”的数据结构，不需要先造第二套纠错系统。
但“保存了一个词”不等于“模型一定能听出来”：现有救援主要覆盖拉丁字母近似拼写，且只加载前 64 个热词。
纯中文术语目前主要依赖首遍识别与用户填写的明确错法替换。

WhisPrompt 的公开资料不足以还原其词典实现。应借鉴可证实的功能，不能把猜测写成该产品的技术方案。

本轮只读取数量，没有摘录私人词条：磁盘 `hotwords` 12 个，实际加载 12 个，`rules` 12 条，当前未触及 64 词限制。

本轮使用现有 Python 环境做无模型、无麦克风的合成函数检查：

- `near_miss('这个是梯度下将', ['梯度下降'])` → `[]`。
- `near_miss('返回Jason数据', ['JSON'])` → `['JSON']`。
- `strong_hits('梯度下降', ['梯度下降'])` → `0`。

这些仅验证门禁及计数的字符范围，不是识别准确率实验。

## 推荐方案

### 第一步：少量术语直接共用个人词典

继续使用当前词典窗口，一个词只维护一份正确写法。“专业术语”不以常不常说划线：偶尔出现、但需要准确写出的名称也可以保存。

- 只知道正确写法：先收录术语，错法可空；英文和缩写可能获得当前救援，纯中文不能承诺仅加词就改善。
- 有真实、稳定的识别错法：补入“容易识别成”，由已有替换层处理。不要凭想象生成大量谐音错法。
- 正常词也可能成立的错法：先审查歧义。例如 `cash` 与 `cache` 都可能正确，不能无条件互换；`context: "zh"` 仅限制语言场景，无法识别专业语义。
- 小批量开始，例如先选 20–50 个实际需要的术语；这是试验建议，不是模型能力保证。计算数量时包含已有个人词。

这一阶段不需要新文件格式、分类界面、联网大模型或重新训练。若批量添加，目前只有错法框支持粘贴整理，正确词语列表没有批量导入入口；不能把已有粘贴能力当成整包导入。

### 第二步：确实需要大量行业词时，再增加领域词包

用户仍从同一个词典入口管理；内部区分个人条目和可选领域词包，例如编程、课程或具体项目。

1. 只启用当前所需领域，不把整本行业词表永久塞进救援解码。
2. 同一正确词合并展示；个人设置优先。错法指向多个词时要求处理冲突，不能静默覆盖。
3. 保存的词库容量与本轮参与救援的词数分别设计；超过上限应明确告知或按用户选择限制，避免悄悄截断。暂不引入自动频次、窗口内容采集或自动学习。
4. 词包作为词条来源独立保存，沿用个人 `dictionary.json` 结构。当前编辑器会重建整个文件，直接加入分类等未知字段会在下一次保存时丢失；若选择改格式，必须同步加载、保存与往返校验。
5. 纯中文热词要独立研究中文近音触发、同音歧义和收益判定。仅放宽字符过滤或取消 64 词限制，不构成完整中文术语支持。

领域词包是后续方案，不是本轮已实现能力。不预先建设词包市场、释义库、语义检索或云端同步。

## 若进入实现，需要覆盖的范围

- 仅少量人工加词：先评测词条，不改识别架构；本轮不实际修改词典。
- 批量导入、分类或词包管理：词典窗口的加载/合并/保存/冲突/撤销，Python 加载端，格式兼容及往返检查一起覆盖。
- 若改中文救援或词数选择：`app/hotwords.py`、`app/recognize.py` 及相关测试；重跑 `work/hotword-prototype/p2_prod_eval.py` 的生产路径 174 与封存 1,314，并增加领域留出集。
- 窗口变更按仓库约定跑离屏 `--dictionary-test`、确认本轮 `TIDY-TEST PASS` 与往返 JSON，不为调研打开真实词典窗口。
- 使用当前 R4 权重固定做 A/B；旧权重的历史数字不能代替本轮证据。面向使用者的变化再同步版本和说明。

## 验收方式

先准备术语清单及独立录音，分别覆盖中文、英文和混说；同一术语有裸词与句中用法。
另加入未说术语的普通句、同音普通词、纯英文、否定句和静音，衡量“救对”与“误改”。
在相同模型与相同音频下比较：现有个人词典、加入术语、加入经确认错法三种条件。
报告术语正确率、整句变化、误插/误改、定稿延迟与内存；草稿立即上屏、用户编辑保护和缓存行为也不能退步。
词表制作材料与验收录音分开，避免只验证填过的错法。固定音频验证通过后，再做实际麦克风听写验收。

本轮未运行模型、构建、原生 UI 或识别回归；未修改个人词典与现有未提交源码。WhisPrompt 词典内部机制仍待官方文档或可访问客户端验证。
