# VoxFix Desktop 1.3.0 听写交互优化

按用户反馈移除未输入文字的保留行为，调整识别反馈；不根据错误转写反推用户原话，也没有硬编码这句话的替换规则。

## 修改

- 正常结束继续补尾，只输入新增文字。切换输入位置、手动编辑或识别前缀回退则取消会话，丢弃未输入部分；移除恢复文件写入和弹窗，结束后清除界面与识别器的会话文本。已存在的 `work/未输入的文字.txt` 已按用户要求删除。
- 直接播放本机 `Windows/SystemApps/MicrosoftWindows.Client.CBS_cw5n1h2txyewy/InputApp/Assets/Dictation` 中的 `BasicListeningEarcon.wav`、`BasicDoneListeningEarcon.wav`、`BasicCancelledEarcon.wav`，分别对应麦克风成功开启、正常停止采集、取消/异常/关闭。通过监听标记避免重复播放；模型加载及无输入目标时不播放开始音。关闭时等待取消音播放完成。音效不是另行合成或复制的音频。
- 保留原 72×72 麦克风与拖动方式，录音时显示蓝色音量波形；静音不制造假波动，处理尾字时显示转动指示。系统关闭界面动画时取消平滑和旋转，只显示即时音量与静态状态。
- 录音缓冲保留原 32×100ms，总缓冲容量为 3.2 秒；读取计时保持 40ms。模型与原默认上下文不变。

## 首字速度与准确率取舍

同一生产 Recognition、相同 174 条 PCM 对比，中文及混合语料为其中 126 条，完全匹配忽略标点但保留英文词边界。

| 方案 | 全部完全匹配 | 中文完全匹配 | 普通句首字，按实时节奏 |
| --- | ---: | ---: | ---: |
| 原生产配置 | 137/174 | 112/126 | 本轮修改前 1190ms |
| 保持上下文，提前送入 320ms 静音 | 130/174 | 105/126 | 873ms |
| 保持上下文，提前送入 640ms 静音 | 128/174 | 104/126 | 1673ms |
| 缩短模型右侧上下文至 6 | 131/174 | 107/126 | 573ms |
| 缩小采集块至 40ms | 132/174 | 107/126 | 1170ms |

四种方案均未采用。较短上下文在否定词、数字和混说上出现回退；40ms 投递在短词、否定句、混说上退步，不能仅因首字更快就替换。比较结果保存在 `work/realtime-probe-20261020/latency-candidates.json` 和 `capture40.json`，复现工具为 `tools/latency_candidate.py`；40ms 通过 `realtime_probe.run(..., frame_samples=640)` 复现。

40ms 候选实际 worker 投递固定普通句测得首字 1170ms；另一轮同时运行模型对比时为 1232ms。原生产配置修改前本轮测得 1190ms，最终保留原配置的新版为 1221ms，仍属于约 1.2 秒，不能宣称显著提速或达到 Windows+H 的实际速度。用户没有提供这段反馈的原始音频，因此没有对其中具体错词作声学定位。
