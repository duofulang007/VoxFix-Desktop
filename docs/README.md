# docs 索引

当前产品：**VoxFix Desktop 1.6.34.0**，首遍识别固定为 SenseVoiceSmall INT8 + Silero VAD + CT-Transformer 标点，
CPU 本地推理。这里的判断都以这一条链路为基准。1.6.29.0 只换识别权重（公开真人语料微调版），代码与交互未改；

（`dictionary.json` 的 `hotwords` 字段，默认关）；1.6.32.0 取消 Ctrl+C 接管，复制缓存只走胶囊按钮；
1.6.33.0 修好右键菜单关不掉（点任意处/选任一项/Esc/收起/退出都关闭）；
1.6.34.0 右键菜单加「词典…」编辑器入口，并按辅音骨架认近音（`Jason`→`JSON`）。

保留原文是为了可追溯（每个结论后面都有原始数据和脚本）。标「现行」的可以直接拿来做决定。
