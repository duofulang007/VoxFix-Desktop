# 右键菜单关不掉

- 版本：1.6.33.0
- 日期：2026-10-23
- 状态：现行

## 现象

右键胶囊弹出的“收起 / 词典 / 退出”菜单一直悬在桌面上：点窗口外任何地方不关，按 Esc 收起胶囊后它还在，
连“退出”之后仍挂在屏幕上。

## 根因

悬浮窗为了不抢输入焦点，创建时带 `WS_EX_NOACTIVATE`（`CreateParams` 里 `0x08080080`）并且
`ShowWithoutActivation = true`。WinForms 的 `ContextMenuStrip` 靠**失焦**（WM_KILLFOCUS / 菜单模式下的
模态过滤器）来判断"用户点到别处了"，这个窗口永远不会被激活，于是永远不会失焦，菜单也就永远不会自动关闭。
Esc 走的是自建键盘钩子，只把动作发给胶囊窗口（隐藏窗口），没有任何代码路径去关闭菜单。

## 改动

`app/Microphone.cs`：

| 位置 | 改动 |
|---|---|
| 新增 `MenuDismissHook` | 菜单打开期间挂 `WH_MOUSE_LL`，任何左/右/中/X 键按下落在菜单矩形外就触发关闭；`Dispose` 卸钩 |
| `menu.Opened` / `menu.Closed` | 打开即建钩子；关闭即卸钩并置空，不会重复挂 |
| `CloseMenu()` | 统一关闭入口，`Dismiss`、`HandleShortcut`（Win+H / Esc）、`MouseDown`、`FormClosing`、`FormClosed`、`VisibleChanged` 全部调用 |
| `VisibleChanged` | 窗口一旦不可见就关菜单（Esc 收起的实际路径） |

关闭请求在钩子回调里只做记录 + `BeginInvoke`，不在低层钩子里直接 `Close()`，避免在钩子执行期间跑关闭逻辑。

## 验证

`--self-test`（1.6.33.0，`work/microphone-self-test.txt`）：

- 菜单项为收起、词典、退出；圆角 Region 保持命中区。
- 打开菜单后 `menuGuard` 非空；用反射取出钩子回调、重放真实 `MSLLHOOKSTRUCT`：
  落在菜单内 → 菜单保持打开且关闭请求计数为 0；落在菜单外 → 菜单关闭、计数为 1、钩子已释放。
- 由菜单项“收起”触发的 `Dismiss` 会关掉菜单；`menu.Close()` 会释放钩子。
- 退出码 0，`work/VoxFix Desktop-test-failure.txt` 未在本轮产生。

`--hotkey-test` 回归通过（键盘钩子与 Ctrl+C 透传不受影响）。

## 回滚

删除 `MenuDismissHook` 与各 `CloseMenu()` 调用即可回到 1.6.32.0 的行为，但菜单会重新变成关不掉的悬浮物。
