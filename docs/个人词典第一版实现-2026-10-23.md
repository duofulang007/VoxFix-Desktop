# 个人词典第一版实现

- 版本：1.6.45.0
- 日期：2026-10-23
- 状态：现行界面实现；当前词表的旧规则保留限制已由用户授权迁移，见[个人词典统一规则](个人词典统一规则-2026-10-24.md)。以下保留当时验证，真实麦克风日用验收待用户使用。
- 前置：[第一版方案](个人词典第一版方案-2026-10-23.md)

## 结果

沿用暖白双栏个人词典，在 926×680 客户区内加入搜索、文字替换预览和救援数量提示。
新建规则默认在中文、纯英文及混说中生效；已有规则的 `context` 原样保留，未自动放开。
本轮没有改动个人 `dictionary.json` 内容或 R5 INT8 权重，也没有引入依赖、分类字段或第二套词库。

## 行为

- 搜索按正确词及错法忽略大小写过滤。右侧正在编辑的词即使被隐藏也保留；选择另一行才切换。过滤后的选词、删除、撤回映射到真实词条索引；添加重复词会清空过滤并定位原条目。
- 正确词可以不填错法；首次给仅热词条目补错法，也按新建规则默认不限语言。既有 `zh` 规则继续保留，详情会标明。正常英文短语不能随意作为错法，否则可能误改；本轮不迁移旧词表。
- 预览使用整个编辑器的当前内容（含未保存改动），通过独立的短命 Python 进程调用生产同一套纯文本规则。不启动模型、不录音、不送字、不落盘、不占用识别进程协议。2 秒超时；输入或词典改变后丢弃旧结果，关闭时释放进程，错误不阻止保存。
- 预览显示纠正后文字、命中的写法与词语；旧中文限定规则被跳过时说明未生效。它不测试语音或热词救援。预览以输入框文字作为完整上下文；实际听写中旧中文限定规则还会参考整轮此前定稿。
- 词语总数、救援候选数和纠错规则数分开显示。仍按顺序最多取前 64 个救援候选，超额明确提示，全部词仍保存，其错法替换不受此上限影响。纯中文词占候选位置但当前不具备同等近音救援能力。
- 同一词条的较长错法优先，避免短错法先吞掉长短语；不重排保存内容。跨词连锁替换、大小写匹配、既有词边界与符号处理保持原语义。

## 文件范围

- `app/dictionary_rules.py`：从 `recognize.py` 移出纯文本规则与热词加载；同一文件的命令行入口只提供 JSON 文字预览。没有另建预览脚本。
- `app/recognize.py`：导入并继续暴露原函数名，现有调用者无需修改；保留本轮开始前已有的标点修复。
- `app/Microphone.cs`：新规则默认值、列表索引映射、预览与计数、离屏自检，版本更新。
- `tools/test_dictionary.py`：新增 6 项文本与预览进程测试。
- README、使用说明、AGENTS 和工具/文档索引同步。其他既有未提交工作不回退、不提交。
