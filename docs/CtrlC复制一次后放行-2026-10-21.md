# Ctrl+C 复制一次后放行

版本：1.6.13.0；日期：2026-10-21。

原因：`CopyReady` 只判断缓存已定稿且有内容，复制成功后仍为 true，导致快捷键持续拦截普通 Ctrl+C。

修改：`app/Microphone.cs` 用 `ShortcutCopyReady` 同时约束快捷键准入与动作处理：窗口可见、缓存就绪且 `recoveryCopied` 为 false 才接管。复制成功后已有的刷新流程立即更新键盘钩子状态；新增未上屏文字通过既有 `KeepRecovery` 清除已复制标志，重新开放一次。剪贴板写入失败保留重试机会。按钮继续使用 `CopyReady`，可手动重复复制。

验证：`--self-test` 覆盖首次复制、复制后放行、重复快捷键不覆盖、缓存增加后重新开放、复制失败可重试、成功重试后释放和按钮重复复制。修复前 `work/copy-once-before.txt` 记录 `Successful cache copy must release Ctrl+C to the target app` 断言失败。修复后 `work/microphone-self-test.txt`、`work/microphone-hotkey-test.txt` 为 PASS，`work/copy-once-self-test-error.txt` 与 `work/copy-once-hotkey-test-error.txt` 无错误。
