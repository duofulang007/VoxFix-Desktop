# 1.4.2 未上屏记忆与复制状态

本次按用户新说明取代 1.4.1 的自动复制及切换后停止录音行为。

- 切换窗口只暂停送字，继续录音、分段识别；没有可编辑目标也可开始录音。使用 Windows 可访问性 Value/Text 模式检测可编辑性，无法确认时只记忆。
- 定稿中已送出的前缀不进入记忆；剩余内容按增量累积，不重复追加。当前会话一旦暂停送字，就保守保持记忆模式。
- 麦克风收音时保留原图标及动效，有记忆则显示小圆点。停止后改为与用户参考图一致的粉色复制胶囊，点击后显示“已复制”，新内容恢复“复制”。不显示正文面板。
- 剪贴板只在点击时写入；失败保留文字。复制后仍保留，右键可清空；右键开始新录音不会清空旧记忆。
- 不新增数据库、磁盘听写记录或依赖包。使用 Windows 自带 UI Automation 程序集。

验证：构建、自检及真实模型 --memory-test 通过；普通输入框可编辑/只读检测通过。完整桌面 --stream-test 两次受到真实鼠标操作影响，不能标为通过。真人麦克风距离、各聊天应用采纳送字未在本次验收。

限制：记忆不跨程序重启；单次录音仍限三分钟。系统接受 SendInput 无法证明每个第三方应用真正展示文字，应用静默丢弃输入仍需单独适配。
