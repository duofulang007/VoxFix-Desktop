# Windows 原版语音输入快捷键调研

日期：2026-10-21。版本：研究记录；产品文档基线 1.6.7.0。状态：历史调研方案。

后续实施：1.6.8 已按用户选择只保留 Win+H、Esc，并使用 Ctrl+C 复制就绪缓存；
本文的 Win+Ctrl+H、Win+Alt+H 建议未采纳。现行规则见[快捷键说明](WinH与Esc快捷键-2026-10-21.md)。

本记录只核对微软官方说明，不改产品代码、快捷键、启动项或系统设置。未在本机实际触发原版听写。
本机只读注册表信息：DisplayVersion 25H2、CurrentBuild 26200、UBR 9457；不根据遗留 ProductName 字符串判断系统代际。

## 官方明确的行为

| 操作 | 原版效果 | 来源 |
|---|---|---|
| Win+H | 打开语音输入并自动监听；出现监听提示后开始讲话 | [语音输入说明][voice] |
| Win+Alt+H | 用键盘导航语音输入菜单；不是第二套听写引擎 | [语音输入说明][voice]、[快捷键表][keys] |
| Win+Space | 切换输入语言/布局；原版听写语言跟随输入语言 | [语音输入说明][voice] |
| 点麦克风 | 停止语音输入 | [语音输入说明][voice] |
| 说“停止听写”“暂停语音输入” | 简体中文支持的停止/暂停语音指令 | [语音输入说明：简体中文指令][voice] |

原版通常需要联网、可用麦克风和文本框光标；支持简体中文及香港、台湾繁体中文。[来源][voice]

## 齿轮设置

官方列出：语音输入启动器、自动标点、粗俗用语过滤、默认麦克风、执行语音指令前的等待时间。
启动器方便在文本框中快速启用听写，不等于开启后持续录音。
上述项目是否全部出现在本机，需要按本机版本核实。[来源][voice]

Fluid dictation 的语法、拼写与填充词调整属于 Copilot+ PC 的英语功能，不能据此推断中文原版有同样能力。[来源][voice]

## 不能从官方页面直接确定的细节

| 按键/场景 | 当前证据边界 | 本机需要记录什么 |
|---|---|---|
| 录音中再次按 Win+H | 官方主说明未列出此状态转换；微软社区答复不等于产品规范 | 停止收音、保留面板，还是停止并关闭 |
| 暂停后再按 Win+H | 官方主说明没有单列 | 恢复原会话、开启新会话、缓存是否保留 |
| Esc | Windows 通用快捷键表写停止/退出当前任务，未单列语音面板 | 是否停止收音、隐藏面板；焦点在文本框和面板时分别测试 |
| Tab / Shift+Tab | 通用对话框中前后移动选项，未给语音面板的实际顺序 | Win+Alt+H 后各控件顺序，能否回到原文本框 |
| Enter / Space | 通用界面的选择/激活受焦点控件影响，不能当全局开始/停止键 | 焦点在麦克风、齿轮、开关时分别测试 |
| Win+Shift+H、双击或长按 Win+H | 所查官方表未定义语音输入动作 | 不先占用，不假定是原版功能 |

上述通用导航语义来自 [Windows 快捷键表][keys]；对语音面板的效果仍是待测项。

## 给 VoxFix 的设计约束

以下是产品建议，**不是原版已验证行为**：

- 先把开始、停止收尾、收起、清空缓存分成四个动作，再决定哪些共用 Win+H。
- 无焦点转缓存是 VoxFix 自己的兜底；收起或停止不应顺手清空缓存。
- Win+Space 保留系统用途；不要拿 Enter、Space、Tab 做全局录音控制，以免干扰输入框。
- Win+Alt+H 可优先沿用“进入语音控件的键盘导航”语义，而不是另起一个无关动作。
- 先实测“再次按 Win+H”和 Esc，再确定最终开关方式；不把当前“重复呼出保持录音”当成已复刻原版。

建议的最小组合如下，尚未实现或绑定：

| 组合 | VoxFix 建议动作 | 说明 |
|---|---|---|
| Win+H | 隐藏/空闲时开始；录音时停止并收尾 | 开始/停止是建议的开关语义，重复按的原版细节仍待实测 |
| Win+Ctrl+H | 复制未上屏缓存 | 只有缓存定稿完成才可复制；空缓存时不覆盖现有剪贴板 |
| Win+Alt+H | 进入语音控件菜单导航 | 沿用原版的键盘导航方向 |

不全局拦截 Esc、Enter、Backspace，不增加清缓存快捷键；避免误操作干扰输入目标或丢失兜底文字。

## 最小本机核验清单

在独立空白文本框测试，不向真实聊天框输入：隐藏→Win+H；录音→Win+H；暂停→Win+H；分别在文本框/面板焦点按 Esc；Win+Alt+H 后依次 Tab、Shift+Tab、Enter、Space；失去输入焦点后再恢复。
每步记录面板可见性、是否收音、焦点位置、正文变化。只需短句验证交互，不做识别准确率评测。
