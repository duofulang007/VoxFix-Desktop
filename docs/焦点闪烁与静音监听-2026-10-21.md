# 1.5.6 焦点切换与监听动效

## 修改

- 恢复流程原先在输入目标尚未更新、音频分界尚未完成时就切回圆形；采集定时器仍与旧目标比较，会切回胶囊。现在目标和音频路由一起提交后才显示圆形，暂停期间不再让旧目标检测抢状态。
- UI Automation 查询验证焦点元素属于当前前台窗口，拒绝其他窗口的过期焦点。只接受可编辑类型，避免桌面列表等带 ValuePattern 的控件被当作输入框。
- 胶囊原先只读取录音状态，一直显示声纹。现在复用圆形监听绘制：讲话显示细声纹，静音切回麦克风，浅色外环继续轻微起伏。

## 验证

- 自检：绘制、讲话保留、静音恢复、弹簧过渡、缓存和长按交互。
- 真实桌面缓存回归：跨窗口过期 UIA 被拒绝；等待音频分界时保持胶囊；连续无输入检测保持胶囊；恢复后只输入新文字；旧缓存手动复制；只读输入框与切换字段。
- 界面冒烟测试、实际桌面像素可见性、再次启动恢复原窗口且无重复实例。
- 已更新 bin/VoxFix Desktop.exe，版本 1.5.6.0。更新前旧实例为空闲麦克风状态。
