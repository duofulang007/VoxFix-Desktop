挑好录音，交给 agent 训练，再用新录音验证。

左侧只有三个模块：录音、训练、验证。应用负责收集和确认，agent 负责训练和正式启用。

保存、归档和验证通过是不同状态。归档不会开始训练；个人验证通过后，仍由 agent 完成通用回归和正式启用。

录音：听清实际说了什么，再改完整文字

  1. 打开胶囊右键 → 词典 → 听写记录。开启左下角「保存听写录音」，从下一轮开始留档；也可直接「补录一句」。没有保存的旧原音不能还原。
  2. 单击只选中；双击、Enter或「打开录音」进入「听音改字」，播放原音，在「修改后的文字（可编辑）」填写完整内容。「选项 → 对照原文」可看原识别、首次草稿或救援前文字。
  3. 要训练就直接勾选编辑框下方「留作训练」，然后「保存」。只改字则不勾；下一条不会自动勾选。保存后自动继续，最后一条回到列表。

实际说：今天不用 Codex，先跑测试。

原识别：今天不用扣desks，先跑测试。

正确全文：今天不用 Codex，先跑测试。

只填 Codex 会丢失整句对应关系；不要润色、删除口头语或补写原音没有的内容。

保存的录音在「录音 → 筛选 → 已保存」回看。点击可继续修改、试听或取消训练勾选。黄=待核对，绿=已保存，蓝=已选训练，灰=已忽略；颜色旁保留文字。

训练：只做二次确认和批次归档

标题旁「！」包含说明，悬停、点击或键盘聚焦可读，腾出的空间用于录音列表。

  1. 进入左侧「训练」，默认「待归档」，显示前面挑选过的录音。在「批次名」填写这批的名称，最多80字。
  2. 点击卡片勾选这次需要交给 agent 的录音，再点击取消；上方显示本批确认数量与时长。已归档录音不会自动重复勾选，确需再次使用可手动选。
  3. 点「归档批次」，确认条数和时长。归档成功后，批次选择框可切换到这份批次查看。
  4. 切换「已归档」选择批次，可看数量、时长、来源文字快照和训练/验证状态。快照保留，后续修改原记录不会覆盖旧批次。底栏「撤回归档」可返回选择，随后「恢复归档」可继续使用原批次。
  5. 点「打开批次」，把实际路径交给 agent。批次包含音频、manifest.json、samples.jsonl 和「下一步.txt」；训练在独立环境执行。

交给 agent 的示例

验证：用训练完成后的新录音作对照

  1. agent 完成训练并登记候选后，进入「验证」选择版本。没有候选时，录音复测和通过保持禁用。
  2. 点「录新音」，写好准备说的完整句子，录制、试听并保存。必须是候选登记之后的新音；不能把训练原音重新提交作为验证。
  3. 单击复测仅选中，双击、Enter或「查看对照」展开结果。应用分别运行原模型和候选，展示原模型 / 候选 / 正确全文。这是不经过词典救援的裸识别。失败时原音保留，可以「重试识别」；多选后可全选/清空并「重试所选」，不会自动通过其他条目。
  4. 逐条检查后点「通过」；不满意在备注填写具体原因后「打回」。通过只是本人确认，正式启用仍由 agent 完成。通过后追加复测会清除旧通过结论。

紫色表示待验证，绿色表示验证通过/已启用，红色表示已打回；状态文字区分具体阶段。验证音频单独保存，不自动进入训练列表。agent 不得一边拿它调参，一边仍称其为独立验收。

三个模块采用统一气泡卡片；右下角数字为当前列表顺序水印，正文可以覆盖它，不是永久录音编号。灰色侧标表示当前查看，蓝色勾和浅蓝底表示批量选中；二者独立。列表背景与页面一致，滚动条轨道用于判断位置。

待归档 ⇄ 已归档撤回 / 恢复，快照保留
待复测 ⇄ 通过 / 打回撤回结论，原音和历史保留

来源批次已撤回时，关联验证暂停；恢复归档后再继续。已实际启用的模型仍由agent执行真正回滚。

批量处理、撤销与前后切换

操作用途
录音 → 多选 → 批量操作点击整张卡片勾选当前可见录音，再点击取消；统一留作训练/取消选择、重新核对或忽略。入选前须每条已核对保存；搜索或筛选变化清空勾选。
批量操作 → 永久删除所选录音…确认数量后删除所选源音频和标注，无法撤销。已归档批次、验证副本保留；仅处理当前可见且勾选的记录。中途失败准确报数并停止。
撤销上次恢复本窗口最近20组保存/状态操作，关闭不保留。外部文件变化会阻止覆盖。
选项 → 还原本次编辑只恢复当前尚未保存的文字和选择；跳过不改录音数据。
重新核对 / 忽略都保留原音和文字；重新核对清除审核与训练选择，忽略可再恢复。
顶部 ← / →，或 Alt+左 / 右记住本窗口最近64个访问位置、搜索、滚动和对照。只切换页面，不撤销已保存数据。未保存修改仍先询问。

内容项目目录内位置

删除恢复纠错选项中确认删除，仅将原JSON改名为 .json.deleted，保留原音。恢复前检查没有同名JSON，或请agent协助。

个人数据不入Git。日常听写档案上限1GiB，不自动清理；补录、批次和验证另占空间。失败目录 .partial 不算成功批次。不要删除未知来源原音或实验结果。
