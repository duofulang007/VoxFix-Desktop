# SenseVoiceSmall 桌面识别架构重构

日期：2026-10-21。产品版本 1.4.0。用户明确选定 SenseVoiceSmall，允许重做语音架构；不纳入 Qwen3-ASR 1.7B。本轮没有增加云服务、润色大模型、设置页、笔记系统或新的任务窗口。

> 当前仍沿用本文的识别架构。本文记录 1.4.0 当时状态，其中“没有全局快捷键”等交互描述已过时；当前使用、快捷键与缓存行为以[使用说明](使用说明.md)为准。

## 最终链路

默认麦克风 → Silero VAD → SenseVoiceSmall INT8 → CT-Transformer 标点 → 定稿输入；当前句单独预览，失败后会话内保留未输入结果供复制。

产品入口仍为项目根目录的快捷方式和 `bin/VoxFix Desktop.exe`，已构建并在 Default 交互桌面启动。程序和窗口仍叫 VoxFix Desktop。

## 解决的问题

- 删除整段累计重识别和 25 秒停止增量的条件。识别窗口由 VAD 和约 10 秒的持续语音上限约束；强制分段在附近安静处切开，未处理的样本带入下一段。
- 草稿与定稿分开。草稿可以修订；已定稿的段落独立提交，下一句不再受整场文字前缀约束，不会因旧标点/字词变化冻结后文。
- 录音线程不等待模型推理。后台按序处理定稿，草稿只保留最新一份，异常显式返回，取消会等待旧推理结束后清理，避免旧线程写入新会话。
- VAD 使用最多32倍自适应增益；ASR 保存原始波形，每个窗口统一增益。逐100ms改变增益曾使快读“好的”变为“cad”，已加入波形相对音量回归。
- 关闭 SenseVoice ITN。在固定金额录音上，开启时“一百二十八元五角”被写成“128元5元角”。关闭后数字保持口述形式，独立模型补标点；正文、英文词边界和小数发生变化则拒绝标点结果。标点推理失败返回原文，不丢弃正确转写。
- 焦点或外部编辑变化时停止输入，收尾后的未输入文字保留在内存，用户点击复制；不自动改剪贴板，不强制切回旧窗口。新录音清空恢复结果，关闭视为主动取消。不自动保存真人音频或听写文本。
- 当前句窗口首次创建曾抢焦点，桌面测试稳定复现。把首次创建移到捕获输入目标之前，隐藏初始化；之后仅用不激活显示。保留预览显示前后前台窗口不得改变的断言，真实输入测试已通过。

SenseVoice 本身非原生流式：这是分段识别和实时当前句预览，不能宣传成边说边向任意目标输入框逐 token 提交。持续不停顿时，定稿通常到窗口边界或主动结束才输入；真实语音停顿使用650ms结束判定。

## 资产与算力

- SenseVoiceSmall INT8：239233841字节，来自原VoxFix已核验模型；tokens 315894字节。
- Silero VAD：643854字节。
- CT-Transformer INT8标点：75519198字节。
- sherpa-onnx 1.13.8 CPU运行库随项目保存。生产运行不再加载 transcribe.cpp 或Qwen模型；旧资产未删除。
- ASR四线程、VAD一线程、标点两线程。13秒整段单次识别测试，2线程约198–203ms，4线程约131–145ms，8线程约123–127ms，故使用4线程。另一次带完整链路加载的资源探针为158–167ms，不能把不同负载下单次数字当保证。
- 完整加载探针约819ms；Python进程工作集466.8MiB、峰值470.7MiB、私有提交951.6MiB。工作集和私有提交是不同指标，均不代表整个应用或系统总内存。见资源报告。
- 当前使用CPU，不占用独显模型显存，不需要Vulkan着色器预热。运行依赖现有Python环境；本次没有重做独立安装包。

哈希：`work/sensevoice-20261021/assets.json`。来源和许可保存在各模型、运行库目录；旧生产源备份在 `work/sensevoice-20261021/previous/`。

## 验收边界

没有完成真人正常坐姿距离、口音、风扇/键盘/回声及各软件长期输入验收；固定录音衰减不是远距离麦克风测试。本轮保留原Windows waveIn默认输入链路，改善了检测与增益处理，不声称更换了系统麦克风前端或加入了回声消除。

程序仍有每次三分钟上限；没有全局快捷键、声学个性化训练或润色大模型。管理员窗口和应用自身光标移动仍可能影响送字。SendInput系统返回成功也不保证每种第三方输入框都真正接收，失败恢复仍需要真人跨应用验收。
