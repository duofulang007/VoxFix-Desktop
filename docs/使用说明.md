# VoxFix Desktop 1.6.0

完全本地的 Windows x64 语音输入。当前识别使用 **SenseVoiceSmall INT8**，配合 Silero VAD 分段和 CT-Transformer 标点，不调用云服务，不加载 Qwen 或润色大模型。

打开项目根目录的 `VoxFix Desktop.lnk`，或 `bin/VoxFix Desktop.exe`。保留项目目录结构、`.venv` 和现有 Python 环境。

## 使用

1. 有输入框时，先点输入位置，再点麦克风开始录音；停顿后将定稿送入原位置。
2. 没有可确认的输入框也能录音。切换窗口或手动编辑后继续收音和识别；约每 250ms 检测当前可编辑输入框。无输入框时保存未送出内容，切回并点进输入框后恢复后续定稿，已留在记忆里的旧内容不会重发。后台按音频采集阶段标记片段，离框期间的音频即使晚返回也只进缓存；恢复输入后旧缓存仍保留，必须手动复制、粘贴；右键可取回，或失焦后在胶囊中复制。不会强行跳回旧窗口；编辑手势或修饰键按住时暂缓送字。
3. 录音中外形只由输入焦点决定：有可编辑输入焦点为圆形（上屏模式）；失去焦点即为胶囊（缓存模式），不等待说话、草稿或定稿。有无旧缓存不影响这两种模式。
4. 无焦点胶囊无文字时显示“监听中”；人声、待识别队列或正在运行的识别/标点任务未结束时显示“转写中”，复制文字变灰并禁用（包括右键复制）。任务全部完成且有缓存时亮起“复制/已复制”；圆形和胶囊讲话时显示细声纹，静音监听时切回麦克风，浅色外环持续轻微起伏。输入目标和音频分界确认后切回圆形，避免恢复期间反复闪烁，只输入后续新话，旧缓存不自动补发。空闲时仍可通过胶囊复制保留的内容。
5. 录音中点击胶囊左侧声纹（含圆形中心位置）结束录音，点击右侧“复制/已复制”只复制，不停录音。空闲时点胶囊即可复制。长按约 0.4 秒会先收尾并清空上一轮缓存，再开始全新录音；松开不会误复制或停止，新一轮可以再次轻点结束。拖动取消长按。右键仍可开始/结束、复制、清空或退出。有待处理内容时提示“转写中”，停顿或结束收齐定稿后可复制。
6. 连续说话会分段处理，每次录音最多三分钟。拖动可以移动位置。无输入框或窗口切换不触发结束；圆形麦克风时点击结束，胶囊时点左侧声纹或右键结束；三分钟上限仍会结束录音。
7. 记忆仅存在当前程序内存中，退出后清空，不保存到磁盘。无法确认可编辑性的应用保守进入记忆模式；SendInput 成功仅表示系统接受送字，不能保证所有应用实际采纳。

麦克风圆形直径 72，胶囊约 106×42（两端半圆、中间直边），按相同面积变形；完整透明画布为 128×96。声纹扩大、监听外环增加向外扩散的双层浅色波环。麦克风与胶囊使用矢量路径及逐像素透明窗口，外轮廓保留半透明抗锯齿，不使用硬边窗口裁剪。状态提示不展示听写正文。讲话/静音状态由 Silero 人声检测决定，音量只控制声纹幅度，避免放大后的底噪使声纹常驻。音频仍从 Windows 默认麦克风采集；没有更改系统输入音量。

## 当前架构

`默认麦克风 PCM16/16kHz → Silero VAD → SenseVoiceSmall → 标点校验 → 定稿输入 / 未上屏记忆 → 点击复制`

- SenseVoiceSmall 是非流式识别模型。这里实现的是**分段识别**，当前句草稿仅在内部处理，不是模型原生逐 token 流式，也不是边说边把所有草稿直接写进目标输入框。
- 声音检测统一使用 100ms 片段，缓冲积压形成的大包先拆分，防止检测与定稿依赖切回输入框才触发。声音检测使用最多 32 倍自适应增益；ASR 保留原始波形，每段统一调整音量，避免逐帧增益扭曲轻声与辅音。
- Silero 阈值 0.30、最短语音 120ms、静音分段 650ms；首尾留 400ms。持续说话到约 10 秒时，在附近较安静的位置切开，剩余音频进入下一段。
- 当前句约每 350ms 尝试更新，过期草稿被替换，不积压成待处理任务。定稿段按顺序处理，之后的修订不会锁死已经完成的整场会话。
- 关闭 ASR 的 ITN 数字改写；固定语料发现它会误写金额。独立标点模型只允许添加标点，改变正文、数字或英文词边界的结果会被拒绝。
- CPU 识别 4 线程、VAD 1 线程、标点 2 线程。不编译 Vulkan 着色器，不占用独显模型显存。

## 验证

- 构建：`./build.ps1`
- 无设备单元测试：`.venv/Scripts/python.exe tools/test_sensevoice.py`
- 语言输出保护：`.venv/Scripts/python.exe tools/test_language_guard.py`
- 真实模型协议与175秒连续会话：`.venv/Scripts/python.exe tools/test_microphone.py`
- 固定174条、完整音频与生产分段对照：`.venv/Scripts/python.exe tools/evaluate_sensevoice.py`
- 界面自检：`bin/VoxFix Desktop.exe --self-test`
- 硬件开关测试：`--capture-test`，仅内存计数，不保存采音。
- 真实模型兜底测试：`--memory-test`，验证无目标继续识别、未送出内容累积、手动复制、胶囊状态和跨录音保留。
- 桌面输入测试：`--stream-test`，在自己的文本框验证真实送字、可编辑目标检测、去重、编辑保护、手动复制和取消；键鼠操作会触发保护并使测试中断。
- 可见性：`.venv/Scripts/python.exe tools/test_desktop_window.py`

验证详情与限制见 `docs/SenseVoice架构重构-2026-10-21.md`。当前固定语料仍有中英术语、英文单词和粤语错误；没有承诺达到 ChatGPT 或 Win+H 的真人准确率。降低录音音量的回归不能替代正常坐姿、真实距离和房间噪声验收。

`docs/` 和其他 `tools/` 中的旧 Nemotron/Qwen 评测属于历史实验，其运行参数不代表当前生产接口。重构前源文件保留在 `work/sensevoice-20261021/previous/`。
