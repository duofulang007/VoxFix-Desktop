**出字与自动纠错（1.6.76.0）**：在原来的兼容输入框中直接说话，草稿快速显示。识别根据上下文调整结果时，系统原位改字，保留正确后文，光标停在最新语音文字的末尾；不会把整段退格删掉再重打。明显缩短的中间候选暂缓，短段定稿仍准确处理数字、否定和标点。尚未支持直接修改的输入框按短段定稿追加。停止收齐尾音，连续录音保留后台接续；输入位置变化后保留未上屏结果。正文实际长度变化仍可能正常换行，但不再因回删后文反复缩高。

微信输入修复（1.6.51.0）：修复中文标点后的字被吞掉或变成重复标点。微信使用专用送字方式；手动编辑或焦点变化后暂停送字并保留缓存。不会自动发送消息，不操作剪贴板；其他软件保持原输入方式。

## 录音、训练、验证（当前操作）

左侧固定三个入口，内容区和底栏与词语页对齐。

1. **录音**：单击只选中；双击、Enter或底栏「打开录音」进入纠错试听，在「修改后的文字（可编辑）」填写实际说出的完整文字。需要训练时直接勾「留作训练」，再保存。保存后可通过「筛选 → 已保存」回看；单纯改字不会自动选择训练。
2. **训练**：「待归档」填写批次名（最多80字），可全选/清空或点击卡片勾选这次交给 agent 的录音，核对条数和时长后点「归档批次」。切换「已归档」选择批次，可看当时的文字快照、数量、时长和训练/验证状态；已有归档快照不被后续改字覆盖，但归档状态可以撤回或恢复。点「打开批次」获取实际路径并交给 agent。已归档录音不自动重复勾选，确需重用可手动再选。
3. **验证**：agent 完成训练和导出后登记候选、来源批次与训练报告。在这里「录新音」，输入完整正确文字，录新音、试听并保存；应用独立跑原模型和候选裸识别，展示三份全文供核对。单击只选中，双击、Enter或「查看对照」查看；失败可「重试识别」，原音保留。「多选」可全选/清空并「重试所选」，只处理所选待识别条目，不自动通过。「通过」只保存本人结论；不满意填写原因后「打回」。正式启用及回滚准备由 agent 完成。

没有已登记候选时，复测和通过按钮禁用。训练原音不允许直接用作新录音验证；验证音频单独存档，不自动进入训练列表。候选、基线、音频、来源清单或报告变化会阻止通过，避免错认版本。个人验证不能代替通用语料、延迟和内存回归。

示例：实际说「今天不用 Codex，先跑测试。」，原识别是「今天不用扣desks，先跑测试。」。完整改正后勾选留作训练并保存 → 在训练页二次确认、归档 → 把批次路径交给 agent → agent 登记候选 → 在验证页说新的句子并核对结果 → 通过或说明问题打回。改写句子不能冒充原录音对应标签。

简短操作见[录音纠错三步教程](录音纠错-三步教程.md)。留档开关从下一轮生效；保存和归档不会立即改变识别效果。

**输入框焦点修复（1.6.47.0）**：ChatGPT 等窗口的旧接口可能只报告外层只读文档；此时补查 UIA，确认焦点属于当前窗口且可编辑后才切回直接输入。真正只读区域仍缓存。快捷键保持 Win+H；当前用户登录后由已有开机启动项在后台待命。

**主动补录（1.6.49.0）**：右键「词典 → 听写记录 → 补录一句」。不需要先添加词语；在「朗读内容」填单词或完整句子，按平常口音录制，停止后试听，点「保存样本」。每段 0.4–60 秒，明显静音会提示重录，到上限自动停止。关闭或重录前处理未保存音频，保存失败保留供重试。保存后回到统一记录列表，仍须人工勾选才会进入训练材料；词语区重复的「录音纠音」页已删除，旧录音全部保留。

## 使用

圆形、胶囊和形变中的外边缘按矢量路径四倍超采样绘制，再高质量缩回原有屏幕尺寸；图标与文字的中间图层同步提高绘制精度，避免边缘台阶及低分辨率图层重复缩放。

悬浮窗不再弹出额外小字提示，包括悬停说明、输入框恢复、复制结果和录音操作说明。窗口本身的状态文字、右键菜单和供屏幕阅读器读取的说明保留。

无输入焦点、麦克风关闭且没有缓存时，胶囊以单层深石墨灰底显示麦克风轮廓和“未开启”，不显示复制图标、内部圆底、分隔线或下划线；悬停轻微提亮，静止时无呼吸动画。已有缓存时仍显示复制状态。

圆形、胶囊和中间形状统一使用内嵌蓝紫暖粉底图、石墨表面、顶部柔光、细亮边与白色图标；底图固定在控件内部，形变只改变裁切外形，不依赖桌面壁纸，不包含桌面背景模糊。右键菜单使用独立的白色卡片。按下时材质和内容整体微缩，焦点形变沿用可打断的等面积弹簧；无缓存的空闲形变始终保留同一个麦克风，随外形连续移动缩放；有缓存的复制内容再做淡入切换，避免图标重影。监听恢复持续向外扩散的双层波环，开关与收尾保持波环相位，声纹只随实际讲话变化，保留转写进度线；关闭系统动画时这些反馈静态显示。未开启、监听中、转写中、复制和已复制的可见笔画统一居中，不随文字长度与复制过渡上下偏移。

点击须在本窗口按下并在可见外形内松开才执行；拖动、移出窗口或失去鼠标捕获取消本次点击与长按，移回后须重新按下。收起会清除按压、悬停反馈和鼠标捕获，再次呼出不会沿用旧手势。

录音时滚动消息（上下或横向）不会暂停送字。焦点仍在输入框时继续输入；点击、拖选和实际焦点变化仍保留输入位置保护。

Win+H 呼出并录音，再按暂停语音但保留窗口，再按继续；只有 Esc 从键盘结束并收起。每次新会话成功开始时清空上一轮缓存，启动失败不清空。

- 替换发生在标点之前，只改写 `from` 列出的写法，不触碰其他内容；文件缺失或写错 JSON 时词典层自动停用，不影响识别。
- 词表按整词匹配，"get up" 不会误伤 "forget upper" 内部。

**热词偏置**：同一个文件里的 `hotwords` 是"解码期"词表，作用在识别本身，不是事后替换。
定稿文本里出现读音接近某个词的片段（`pyython`、`gitthub`、`J SON`）时，会用偏置解码把这段音频复解一次；
复解结果里出现的词表词更多才采用，否则原样保留。稳定上屏使用处理完成的定稿；不先输入救援前的草稿再回改。

```json
{
  "hotwords": ["GitHub", "Python", "API", "JSON", "PDF", "WiFi"],
  "rules": [
    { "to": "GitHub", "from": ["get up", "git up"] }
  ]
}
```
当前完整热词与纠错规则以项目根 `dictionary.json` 为准，文中示例不是完整词表。

- **不写 `hotwords` 就不启用**：行为与 1.6.30.0 完全一致，没有额外开销，不会多占内存。
- 写入后第一次真正触发会多约 1 秒（加载第二个解码会话），之后每次约 35–60 毫秒；
  闲置三分钟自动释放那部分内存。没命中近音片段的句子完全不受影响。
- 能修的是"读起来像但写错"的情况（多字母、少字母、被空格拆开）；首个音节就听错的
  （例如 Kotlin 被听成 codetland、Java 被听成 Javava）和解码期插不进 token 的词，这一版还救不回来。
- `rules` 那层事后替换照旧生效，两层并存：先偏置，再替换，最后加标点。
开始和收尾不会为了短暂的处理状态把胶囊缩成圆形或闪切成声纹；监听波环保持连续，准备期间不闪出复制图标。实际输入目标变化时仍正常切换圆形与胶囊，讲话时仍显示声纹。

登录后台入口和撤销方法见[当前快捷键说明](WinH后台接管与准确率复核-2026-10-25.md)。

窗口直接呼出，没有淡入、上浮或缩放。有输入框首帧就是圆形，没有输入框才是椭圆；显示前完成工作线程焦点判定和新会话准备，不先画旧形状。
首次打开和再次呼出都会自动开始录音识别，不需要再点麦克风。冷启动先等待本地模型就绪；
通过 Win+H 呼出时按下即开始请求，不必松开 Win；录音中按 Win+H 则暂停并收齐尾字，窗口保留。
拖动后的位置保存在 `work/window-position.txt`；收起、退出重开都恢复该位置，显示器断开时回到可见范围。
右键“收起”会先结束当前录音并收齐尾字，再隐藏窗口，保留进程、模型和未上屏缓存。菜单本身点窗口外任意位置、选任一项、按 Esc 都会关闭，不会一直悬在桌面上。
再次运行程序或现有快捷方式即可原位呼回，不抢走输入焦点；Win+H 已由程序接管。

1. 有输入框时，先点输入位置，再点麦克风开始录音；草稿识别到文字即输入，便于参考已说内容继续组织下一句话。中间修正原位替换当前语音文字（1.6.76.0 起不再限制为末尾若干字符），较大变更等当前短段定稿后处理；不修改用户原文或已完成段落。手动编辑、切换焦点或送字不完整后暂停送字并缓存剩余结果，重新确认输入位置后继续新话。
2. 没有可确认的输入框也能录音。切换窗口或手动编辑后继续收音和识别；约每 250ms 检测当前可编辑输入框。无输入框时保存未送出内容，切回并点进输入框后恢复后续定稿，已留在记忆里的旧内容不会重发。后台按音频采集阶段标记片段，离框期间的音频即使晚返回也只进缓存；恢复输入后旧缓存仍保留，必须手动复制、粘贴；复制只用失焦后胶囊右侧的按钮（Ctrl+C 不被接管，始终是原应用的普通复制）。不会强行跳回旧窗口；编辑手势或修饰键按住时暂缓送字。可编辑性判定是三态：可写就送字；只读文本框仍进缓存；Electron、Flutter、自绘外壳优先用 MSAA 获取实际焦点：WorkBuddy 可编辑输入框送字，只读文件预览进缓存；真正无法报告输入目标的窗口仍按“无法确认”保留兼容送字。
3. 外形只由输入焦点决定，录音中和空闲时都一样：有可编辑输入焦点为圆形（上屏模式）；失去焦点即为胶囊（缓存模式），不等待说话、草稿或定稿。空闲时每 400ms 复查焦点，形状随焦点来回变化，不必先录一句话才知道结果。有未上屏缓存时胶囊始终是复制按钮，与焦点无关。
4. 无焦点胶囊无文字时显示“监听中”；人声、待识别队列或正在运行的识别/标点任务未结束时显示“转写中”，复制文字变灰并禁用。任务全部完成且有缓存时亮起“复制/已复制”；圆形和胶囊讲话时显示白色细声纹，静音监听时切回白色麦克风，双层浅色波环持续向外扩散，石墨表面轻微明暗呼吸。输入目标和音频分界确认后切回圆形，避免恢复期间反复闪烁，只输入后续新话，旧缓存不自动补发。空闲时仍可通过胶囊复制保留的内容。
5. 录音中点击胶囊左侧声纹（含圆形中心位置）结束录音，点击右侧“复制/已复制”只复制，不停录音。空闲时点胶囊：有未上屏文字时复制，没有缓存（空闲椭圆、显示“未开启”）时直接开始录音。长按约 0.4 秒先收尾，再开始全新录音；新会话成功开始后清空上一轮缓存；松开不会误复制或停止，新一轮可以再次轻点结束。拖动取消长按。右键菜单是白色卡片，三项各带图标（收起 / 词典 / 退出），点窗口外任意位置、按 Esc 或选任一项即关闭；录音开关用 Win+H 或左侧按钮，复制只用右侧按钮，清空旧缓存用长按开始新一轮。有待处理内容时提示“转写中”，停顿或结束收齐定稿后可复制。
6. 连续说话按短段处理，后台每三分钟结束一个内部识别轮次并接续下一轮，持续收音，保留已上屏正文与未上屏缓存。拖动可以移动位置。无输入框或窗口切换不触发结束；圆形麦克风时点击结束，胶囊时点左侧声纹或按 Win+H 结束。
7. 记忆仅存在当前程序内存中，退出后清空，不保存到磁盘。无法确认可编辑性的应用保守进入记忆模式；SendInput 成功仅表示系统接受送字，不能保证所有应用实际采纳。

麦克风圆形直径 72，胶囊约 106×42（两端半圆、中间直边），按相同面积变形；完整透明画布为 128×96。共用底图与材质直接跟随矢量外轮廓，监听显示向外扩散的双波环，不增加独立的实心内圆。麦克风与胶囊使用逐像素透明窗口，外轮廓保留半透明抗锯齿，不使用硬边窗口裁剪。状态提示不展示听写正文。讲话/静音状态由 Silero 人声检测决定，音量只控制声纹幅度，避免放大后的底噪使声纹常驻。音频仍从 Windows 默认麦克风采集；没有更改系统输入音量。

形变使用接近零回弹的收敛弹簧：约 256ms 完成 90% 变化、304ms 完成 95%，到达后不反复摇晃。快速切换时保留当前形状与速度，不从头播放；监听波环、圆形大图标到胶囊小图标的连续缩放保持现有行为。

## 当前架构

`默认麦克风 PCM16/16kHz → Silero VAD短分段 → SenseVoiceSmall草稿 → 个人词典 → 即时上屏与受保护原位纠错；定稿 → 救援/词典/标点 → 当前段一次对齐 / 未上屏记忆 → 点击复制`

- SenseVoiceSmall 是非流式识别模型。生产开启草稿，至少约550ms音频后开始尝试，随后约350ms调度一次；实际首字还包含检测、推理、通信与送字时间，不承诺固定延迟。较大分歧暂缓期间可能有数秒不更新，已有草稿继续可见。
- 声音检测统一使用 100ms 片段，缓冲积压形成的大包先拆分，防止检测与定稿依赖切回输入框才触发。声音检测使用最多 32 倍自适应增益；ASR 保留原始波形，每段统一调整音量，避免逐帧增益扭曲轻声与辅音。
- Silero 阈值 0.30、最短语音 120ms、静音分段 650ms；首尾留 400ms。连续语音时长参数由10秒缩短到4秒，强制边界在邻近较安静处切开，剩余音频进入下一段。参数不是上屏延迟的硬上限。
- 定稿段按顺序处理并按索引去重，与本段草稿身份对齐。纯追加立即发送；非定稿的错字修正由 `InPlaceText` 原位替换当前语音文字（1.6.76.0 起），不再按公共前缀限制为末尾 8 个 UTF-16 字符，也不发送左右移动或 Delete。已完成段落与正确后文保持不动，光标停在语音文字末尾。后台换轮排空尾音，保留同一来源组、累计录音位置、送字账本和保护，跨边界余包继续处理。听写档案记录真正生成的首次草稿，不补写旧稳定模式的空字段。
- 关闭 ASR 的 ITN 数字改写；固定语料发现它会误写金额。独立标点模型只允许添加标点，改变正文、数字或英文词边界，以及删除或替换已有标点（如 `.NET` 的点）的结果会被拒绝并保留原文。识别结果本身已经带标点，标点模型对已有标点位置只判定不叠加：它在已有标点旁插入的第二个标点会被丢弃，原文标点、小数点和 `？！` 这类有意义的连续标点不受影响，所以定稿不会再出现 `。。`、`，，`。
- CPU 识别 4 线程、VAD 1 线程、标点 2 线程。不编译 Vulkan 着色器，不占用独显模型显存。

## 录音管理与状态

筛选仅全部、待核对、已保存、已忽略四项；刷新、统计与说明在筛选菜单内。重新核对保留文字和原音，清除核对、训练选择与忽略；忽略不等于已核对。「还原本次编辑」只恢复未保存编辑，「撤销上次」恢复当前窗口最近20组保存或状态操作，关闭不保留。外部文件变化会阻止覆盖；切页或关闭会先处理未保存修改。

录音列表「多选」后整卡点击或空格勾选，全选只针对当前可见范围，搜索或筛选变化清空勾选。批量操作可留作训练、取消训练、重新核对或忽略，入选前必须已试听核对并保存。

「批量操作 → 删除录音」会确认永久删除数量，删除所选源WAV和JSON，无法撤销；既有归档和验证副本保留。外部改动会阻止整组处理；中途失败报告完整删除条数并停止，当前条可能部分清理。纠错页单条删除仍是移出列表、保留原音和.json.deleted索引。

标题旁后退/前进支持Alt+左/右，保留本窗口最近64个访问位置、搜索筛选、滚动和对照；只导航，不撤销数据。词语页隐藏箭头。卡片数字是当前列表顺序，不是永久身份；灰色定位线与蓝色勾选独立。黄/绿/蓝/灰状态同时保留文字，蓝色仅表示选作材料。

## 归档和结论撤回

已归档中选中批次，底栏「撤回归档」保留原音、清单、名称和历史；现存且仍入选的源录音可回待归档重新挑选。随后「恢复归档」复用原快照，不重新复制；已删除的源录音不会重建。

验证通过或打回后可「撤回结论」返回待复测，原音、对照与旧结论历史保留。通过后新增复测也使旧结论失效。来源撤回暂停关联候选录新音、识别、通过与启用记账；恢复来源后继续。来源清单未变但归档原音已变，也会阻止推进验证。实际启用模型的回滚仍由agent执行。

## 外观主题

1.6.84.0：雾息边缘改为高分辨率透明度柔化，图标、声纹和复制文字保持清晰。

1.6.90.0：「混沌」复用 ChatAni 的球面着色器，以细密半透明双面网格、慢速旋转和连续三维噪声形成流体褶皱。开麦时为青蓝色流动圆球，讲话时褶皱加深；停麦渐变为低亮度蓝灰色并静止，圆球与胶囊过渡保持连续帧，音量映射限制在圆球主体仍清楚的范围。整个主题不绘制麦克风或暂停图标；独立处理时仅有细小进度弧，错误时球体转暖色并显示感叹号。需要缓存状态时，球体缩到左侧，右侧显示监听中、转写中、复制或已复制。系统关闭动画时停止旋转和位移，仍保留状态反馈；快捷键、拖动、暂停、缓存与复制规则不变。不支持 GPU 着色器的环境使用低密度软件绘制。
