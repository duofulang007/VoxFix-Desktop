# 仓库清理与维护入口

版本：1.6.24.0。日期：2026-10-21。状态：现行。

## 清理范围

- 删除 34 个旧 Nemotron/Qwen、上下文、热词及旧协议实验脚本。它们依赖被替换的识别接口或外部旧环境，不是当前回归入口。源码保留在 Git `5209268`，恢复说明见 `tools/README.md`。
- `app/recognize.py` 删除旧实验的 `STATS` 全局列表、计时调用和不再使用的 `time` 导入。现行生产和测试无读取方，避免后台进程持续积累无用的耗时数据。
- `tools/p0_score.py` 保留现行调用的四个评分函数，删除依赖安卓绝对路径的旧 CLI、分组报表、百分位统计及其专用依赖；现行导入路径不变。
- `app/Microphone.cs` 删除重复的窗口类型缓存，直接查询窗口类名，避免跨线程维护这个字典；删除生产路径已不使用的“粗粒度窗口直接 Unknown”参数与对应旧断言，保留实际 MSAA/UIA 三态判定及熔断。
- README 精简为使用、安装、验证与文件入口；AGENTS 修正过时的外文重解、脚本策略和测试说明；新增工具索引，并明确旧脚本的 Git 恢复方式。
- 历史技术记录仍保留；SenseVoice 架构文标明早期交互已过时，防止将“没有全局快捷键”误当作现状。
