# 错法框的整理：粘贴一串写法自动拆行去重

- 版本：1.6.38.0（1.6.37.0 曾把它做成右键菜单项，已撤掉）
- 日期：2026-10-23
- 状态：现行
- 前置：[个人词典-编辑器入口-2026-10-23.md](个人词典-编辑器入口-2026-10-23.md)

## 为什么改

1.6.37.0 把"整理"做成了右键菜单里的一项，处理剪贴板文本。用户指出这不是他要的：

> 我说的整理是粘贴的这个输入框。就可以整理，而不是在外面挂一个控键啊。

他要的是**在词典窗口的「错法」框里**：把一串用标点串起来的写法贴进去，自动变成一行一个、去掉重复，
不用再去外面点按钮。所以菜单项撤掉，能力搬进错法框。

## 现在的行为

- **粘贴即整理**：在「错法」框里 Ctrl+V 一串 `col death。koex。koex。colexs,cols；kos|koldex`，
  松手后自动变成：

  ```
  col death
  koex
  colexs
  cols
  kos
  koldex
  ```

- **「整理」按钮**：框右上角，手动对当前内容执行同一套规则。
- 拆分符：`。！？；，、,;|`（全角半角都算）与换行/制表；
  **空格不拆**，所以 `col death` 仍是一条写法。
- 每条会去掉首尾空白、引号、括号、`「」`，段内多余空格压成一个；**忽略大小写去重**。
- 整理不改「词」本身：左边选的是哪个词，这些写法就都属于它。保存后下一句生效。

## 边界

- 整理只做"拆行 + 去重 + 去杂质"，**不会猜哪个写法是对的**：正确写法由左边的「词」（例如 `Codex`）决定。
- 在菜单里点不到整理 —— 它只存在于词典窗口，非词典场景不需要它。
- 编辑器的保存仍会重写整个 `dictionary.json`（`hotwords` 写全部词、`rules` 只写有错法的词，
  `context` 固定 `zh`）。

## 验证

`--dictionary-test` 除了离屏渲染窗口，还会把一段乱串喂给错法框并打印整理结果，不用开界面：

```powershell
.\bin\VoxFix Desktop.exe --dictionary-test
# DICTIONARY-TEST current=0 text=48 | GitHub:6 | ... | Codex:7
# TIDY-TEST col death / koex / colexs / cols / kos / koldex
```

第一行是各词的错法条数；第二行是整理结果（`/` 表示换行）。截图仍写 `work/dictionary-dialog.png`，
往返 JSON 仍写 `work/dictionary-roundtrip.json` 供 Python 侧解析。
