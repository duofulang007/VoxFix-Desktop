# APP 与 API 拆字规则修正

版本：1.6.46.0（仅词典内容与回归测试，未改程序版本）；日期：2026-10-24；状态：现行。

新规则的最长错法优先只适用于同一词条，跨词条仍按文件顺序连锁替换。API 词条早于 APP，原 `A P → API` 会将 `A P P` 改成 `API P`，APP 的新规则无法再匹配。

删除 API 的歧义错法 `A P`，保留 `a p i`、`api i`、`api`；APP 新增 `a p p`，保留原 `app P`、`app P P`。单独 `A P` 保留原文，不凭缺失字母猜 API。未更改共享替换顺序、模型、热词救援或词典适用语言。

回归测试 `tools/test_dictionary.py` 使用实际生产词典，先复现 4 项失败，修改后 10 种文本全部符合预期，覆盖英文、中文句内、原 APP 错法与 API 反例。完整词典测试 7 项、协议单元 26 项、热词 14 项、语言守卫 2 项均通过。日志 `work/app-api-test_*.log`。修改前词典备份为 `work/dictionary-before-app-api-20261024.json`。

只修改可动态重载的词典数据，不需要重建或重启程序；未进行真人麦克风识别准确率验收，不保证识别器每次输出这些拼写。
